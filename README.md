# Wedding RSVP App (Local-First)

A simple, open-source desktop application to send wedding invitations via Telegram and collect RSVP responses.

## ✨ Features (Alpha)
- Local-first (runs on your machine)
- Upload guest list (CSV/Excel)
- Send Telegram invitations
- Track delivery status
- Collect RSVPs via local server

## 🛠 Tech Stack
- Python
- Flet (UI)
- FastAPI (backend)
- SQLite + SQLAlchemy
- Telethon (Telegram)
